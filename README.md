# Collab Dev Platform

This is the first foundation for the collaborative coding platform.

MVP loop:

Create -> Invite -> Build -> Collaborate -> Change -> Review -> Approve -> Run

## First local commands

```bash
npm install
npm run dev
```

## Current foundation

- React web app first
- TypeScript
- Vite
- Supabase-ready environment variables
- Workspace-first UI placeholder

No paid services, AI calls, or runtime execution are wired yet.
